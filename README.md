# LunaClient

LunaClient - модифицированная версия DDNet клиента с дополнительными визуальными функциями и улучшениями.


## Полезное
[Discord](https://discord.gg/VmejRyTs)

## Основа

За основу взят [T-Client](https://github.com/sjrc6/TaterClient-ddnet) - популярный модифицированный клиент DDNet.

## Что добавлено

### Визуальные эффекты
- Система крыльев (загрузка своих PNG файлов)
- Эффекты следов (Sparkle, Confetti, Fire, Ice, Smoke, Lightning)
- Улучшенные эффекты лазера с многослойным свечением
- Траектория лазера с предсказанием попадания

### Масштабирование
- Масштабирование оружия (50-300%)
- Масштабирование хука (50-300%)
- Масштабирование персонажа (50-300%)

### Управление Dummy
- Отображение информации о dummy (позиция, скорость, угол)
- Биндинги для управления (pseudo fly, deepfly, 45°, small sens, jump)

### Интерфейс
- Анимация чата со скольжением

## Версия

Текущая версия: **1.3**  
Основана на: **DDNet 19.8**

## Совместимость

Все изменения совместимы с официальными серверами DDNet.
